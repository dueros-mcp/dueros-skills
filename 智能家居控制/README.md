# 智能家居控制

围绕家庭空间、智能屏、IoT 设备和家庭场景编排的技能。

适合放这里：

- 设备控制：灯光、空调、窗帘、电视、投影、扫地机、门锁、插座、智能屏。
- 智能屏能力：设备管理、文本播报、语音指令、拍照、图片/视频/音频推送。
- 场景模式：睡前、起床、离家、观影、起夜、学习、做饭、派对。
- 家庭照护：儿童睡前/起床、老人夜间辅助、家庭安全检查。
- 家庭场景辅助：家庭视觉感知、快捷指令、自定义场景编排。
